# 🧪 C-Lab-Quest

Welcome to **C-Lab-Quest** – a journey through the essential building blocks of programming in C! This repository contains all the lab work I completed during my Programming Fundamentals course.

## 🚀 About This Repo

This repository is a compilation of various hands-on programming exercises and lab tasks that helped me grasp the core concepts of the C programming language.

Each lab was designed to teach and reinforce a different fundamental topic in C programming, such as:

- ✅ Data Types & Variables  
- ✅ Input/Output Handling  
- ✅ Conditional Statements (if, else, switch)  
- ✅ Loops (for, while, do-while)  
- ✅ Functions and Recursion  
- ✅ Arrays and Strings  
- ✅ Pointers  
- ✅ Structures and File Handling
